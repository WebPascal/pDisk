# pDisk 云盘

[English](README.md)

基于 WebPascal 5 的轻量级自托管云盘系统，支持文件上传下载、分享、多语言（47 种语言）和后台用户管理。无需数据库服务器，开箱即用 SQLite。

## 功能特性

- **用户注册与登录** — JWT Token 身份验证
- **文件上传** — 拖拽上传、多文件队列、进度显示、保留原始文件名
- **文件下载** — 按原始文件名下载
- **文件分享** — 密码保护分享链接，分享页支持预览/下载/播放
- **目录管理** — 创建、浏览、删除；树形视图支持跨目录复制
- **文件预览** — 图片、音频、视频、PDF、DOCX、XLSX、PPTX、常见文本文件
- **音乐播放器** — 播放列表、播放模式（顺序/随机/单曲循环）、首尾跳过 8 秒
- **磁盘配额** — 按用户设置配额，可配置默认配额
- **后台管理** — 用户列表/启用禁用/删除、文件浏览、文件删除、分享管理
- **磁盘同步** — 文件系统与数据库双向校准，含文件大小校验
- **多语言** — 47 个语言包，根据浏览器语言自动切换
- **响应式界面** — 移动端和桌面端，悬浮按钮支持拖拽记忆位置

## 运行要求

| 组件 | 用途 |
|------|------|
| `WebPascal.exe` | Web 服务引擎（端口 8833） |
| `SrvConfig.ini` | 服务配置 |
| `script/` | WebPascal 5 后端脚本 |
| `www/` | 前端静态资源 |
| `sqlite.db` | SQLite 数据库（init_db 自动创建） |

## 快速开始

### 1. 初始化数据库

将 `WebPascal.exe` 和所有项目文件放在同一目录，运行：

```
WebPascal.exe
```

然后在浏览器中调用一次初始化接口：

```
http://localhost:8833/ask/init_db.api
```

> 初始化成功后请删除 `init_db.api`，防止重复初始化。
> `init_db_share.api` 用于重置分享数据，使用后请移出脚本目录。

### 2. 注册

- **第一个注册的用户自动获得管理员权限。**
- 后续注册用户为普通用户。
- 默认磁盘配额为 **10 GB**。修改 `sqlite.db` 中 `FQuota` 字段默认值，或修改 `init_db.api` 中的值即可调整。

### 3. 访问

| 地址 | 说明 |
|------|------|
| `http://localhost:8833` | 本地实例 |
| `https://zjkpi.com` | 在线体验 |

自行注册体验，第一个用户即为管理员。

## API 接口

所有接口返回 JSON：`{"code": 200, "msg": "...", "data": {...}}`

| 接口 | 方法 | 说明 |
|------|------|------|
| `/ask/login.api` | POST | 登录（用户名、密码） |
| `/ask/register.api` | POST | 注册（用户名、邮箱、密码） |
| `/ask/change_pwd.api` | POST | 修改密码（Token + 旧/新密码） |
| `/ask/upload.api` | POST | 上传文件（FormData） |
| `/ask/upload2.api` | POST | 上传（备用接口） |
| `/ask/file_list.api` | GET | 获取目录文件列表 |
| `/ask/file_copy.api` | POST | 复制文件（fid、目标目录） |
| `/ask/file_delete.api` | POST | 删除文件（fid） |
| `/ask/dir_create.api` | POST | 创建目录（名称、父路径） |
| `/ask/dir_delete.api` | POST | 删除目录（路径） |
| `/ask/dir_tree.api` | GET | 获取完整目录树 |
| `/ask/disk_info.api` | GET | 磁盘用量（已用/配额） |
| `/ask/settings_get.api` | GET | 读取全局配置 |
| `/ask/settings_list.api` | GET | 列出所有配置 |
| `/ask/settings_update.api` | POST | 更新配置 |
| `/ask/share_create.api` | POST | 创建分享链接 |
| `/ask/share_delete.api` | POST | 删除分享 |
| `/ask/share_view.api` | GET | 查看分享页 |
| `/ask/share_my_list.api` | GET | 列出我的分享 |
| `/ask/share_admin_list.api` | GET | 后台：列出所有分享 |
| `/ask/admin_user_list.api` | GET | 后台：用户列表 |
| `/ask/admin_user_toggle.api` | POST | 后台：启用/禁用用户 |
| `/ask/admin_user_delete.api` | POST | 后台：删除用户 |
| `/ask/admin_user_quota.api` | POST | 后台：设置用户配额 |
| `/ask/admin_file_browse.api` | GET | 后台：浏览用户文件 |
| `/ask/admin_file_delete.api` | POST | 后台：删除用户文件 |
| `/ask/admin_dir_delete.api` | POST | 后台：删除用户目录 |
| `/ask/reset_pwd_request.api` | POST | 申请重置密码 |
| `/ask/reset_pwd_list.api` | GET | 列出待处理重置申请 |
| `/ask/reset_pwd_process.api` | POST | 批准/驳回重置申请 |
| `/ask/sync_disk_usage.api` | GET | 磁盘双向同步 |
| `/ask/verify_token.api` | GET | 验证 JWT Token |
